# Diagnostics

The `diag` utility allows inputs to be monitored and motors to be exercised, which
can be helpful in diagnosing problems with models.

## Instructions

Select a motor using the numeric keys (1-4). The currently selected motor can be
identified by the inverse text on the screen.  Once selected, a motor can be
turned on (clockwise or counter-clockwise) using the `<` and `>` keys. Hitting
the `spacebar` will turn off the selected motor.  Any other key will stop *all* 
motors.
